I'm **Abdulrahman Suleiman**, a software engineer and independent researcher interested in how software and machine learning systems behave when their assumptions fail.

My work sits between **artificial intelligence, cybersecurity, and systems engineering**. I build software, study its failure modes, and explore practical ways to make automated systems more secure, testable, and reliable.

I am particularly interested in three areas:

- **Adversarial Machine Learning:** Testing how models respond to manipulated inputs, data poisoning, evasion attempts, and changes in data distribution.
- **AI-Assisted Security Analysis:** Exploring how machine learning, static analysis, and automated testing can help identify weaknesses in software.
- **Secure Systems Architecture:** Designing APIs, backend services, authentication workflows, and state-management systems with security and maintainability in mind.

Alongside security research, I work on full-stack applications and applied AI projects. I use Python and TypeScript frequently, with tools including React, Node.js, PostgreSQL, and Docker.

I care about the decisions behind a system: where data is validated, how authorization is enforced, what happens when a service fails, and whether a model's output can be trusted.

My longer-term research interests include adversarially robust learning, automated vulnerability discovery, and AI-assisted vulnerability remediation.

I'm preparing for research-focused Master's and direct-entry PhD opportunities in **AI and Cybersecurity**.
