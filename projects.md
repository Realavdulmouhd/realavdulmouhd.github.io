## Security & AI Research

### SentinelAI — Intelligent Intrusion Detection

**February 2026 · Security Research**

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Machine Learning](https://img.shields.io/badge/Machine_Learning-333333?style=flat-square)
![Network Security](https://img.shields.io/badge/Network_Security-176B5B?style=flat-square)

SentinelAI explores machine-learning-based network intrusion detection. The pipeline is designed around traffic feature extraction, suspicious-activity classification, and interpretable detection results.

The main engineering challenge is separating unusual but legitimate traffic from actual attacks while keeping false positives manageable.

**Focus:** Traffic analysis, intrusion classification, model evaluation, and security monitoring.

### FederatedGuard — Privacy-Preserving Machine Learning

**2025 · Applied ML Research**

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Federated Learning](https://img.shields.io/badge/Federated_Learning-333333?style=flat-square)
![Privacy](https://img.shields.io/badge/Privacy-176B5B?style=flat-square)

FederatedGuard investigates how machine learning models can be trained across separate clients without collecting their raw datasets in one place.

The work focuses on local model updates, aggregation, uneven data distributions, and the trade-offs between privacy, communication overhead, and model performance.

**Focus:** Distributed training, federated optimization, and privacy-aware ML.

### PromptShield — Adversarial LLM Testing

**2023 · AI Security Prototype**

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![LLM Security](https://img.shields.io/badge/LLM_Security-333333?style=flat-square)
![Red Teaming](https://img.shields.io/badge/Red_Teaming-176B5B?style=flat-square)

PromptShield is a testing framework for examining how language models handle hostile or misleading instructions.

It organizes adversarial prompts into repeatable test cases and examines failures such as instruction overriding, injected context, and unsafe responses.

**Focus:** Prompt injection, model evaluation, and adversarial testing.

## Applied Systems & Engineering

### KanoLife — Browser-Based Life Simulation

**December 2025 · Full-Stack Engineering**

![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)
![Node.js](https://img.shields.io/badge/Node.js-339933?style=flat-square&logo=nodedotjs&logoColor=white)
![Simulation](https://img.shields.io/badge/Simulation-176B5B?style=flat-square)

KanoLife is a browser-based life simulation built around characters, relationships, work, housing, and an evolving virtual economy.

A central design concern is state consistency. Actions such as buying an item, accepting a request, or updating a character's progress need to remain consistent between the interface and the backend.

The project explores server-authoritative state management, persistence, validation, and connected gameplay systems.

**Focus:** Backend architecture, persistent state, and simulation logic.

### AegisHand AI — Gesture-Based Computer Control

**2024 · Computer Vision**

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Computer Vision](https://img.shields.io/badge/Computer_Vision-333333?style=flat-square)

AegisHand AI is a hands-free computer interaction project that uses camera input to recognize hand movements and map them to interface actions.
