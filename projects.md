### Security & AI Research

#### SentinelAI - Intelligent Intrusion Detection (2026)
An autonomous network defense pipeline built to inspect high-throughput packet flows, identify intrusion patterns, and generate interpretable threat diagnostics using supervised and semi-supervised classifiers.

#### FederatedGuard - Privacy-Preserving Machine Learning (2025)
A decentralized training environment evaluating federated optimization algorithms across partitioned client nodes, maintaining model convergence without centralizing raw telemetry or private datasets.

#### PromptShield - Adversarial LLM Testing Suite (2023)
An automated red-teaming toolkit designed to test language models against instruction escapes, recursive prompt injections, and indirect context poisoning.

#### MalwareMind - Interpretable Binary Classifier (2022)
A PE-header and static analysis tool pairing tree-based decision ensembles with feature attribution graphs to highlight why flagged binaries exhibit malicious characteristics.

#### VoiceTrust AI - Deepfake Audio Detection (2021)
A signal-processing pipeline analyzing spectral anomalies and acoustic feature drift to verify authentic human speech and flag synthetic voice clones.

### Applied Systems & Engineering

#### KanoLife - Browser Simulation Engine (2025)
A persistent web life simulation built around localized cultural dynamics, commerce, and character progression, driven by an authoritative state backend.

#### AegisHand AI - Touchless Gesture Control (2024)
A computer vision interface translating real-time hand landmark topologies in to low-latency OS input commands for touchless desktop navigation.

#### AI VoiceForge - Multilingual Conversational Agent (2025)
A modular voice interface integrating local speech-totext models, prompt routing pipelines, and multi-turn context memory for multilingual developer assistance.

#### Face Recognition System - AI-Based Facial Identification (2023)
An AI-powered facial recognition system designed to detect, identify, and verify individuals using facial features. It again uses computer vision along with machine learninig to support identity verification, automated attendance tracking, and secure access control.
